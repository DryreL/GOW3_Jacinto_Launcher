v0.3.6
- Graphics Detail Mode "Ultra" Crash Fix:
  * Fixed a rendering thread crash shortly after loading a level with Game Settings > Graphics detail mode set to Ultra ("Assertion failed: Offset != INDEX_NONE [UnAsyncLoading.cpp] [Line: 843]" in FTexture2DResource::LoadMipData / FUpdateMipCountCommand).
  * Root Cause: The Ultra preset enabled bUseMaxQualityMode=True, which forces the texture streamer to request top mip levels that are not present in the cooked packages (bulk data offset = INDEX_NONE).
  * Solution: Ultra now keeps bUseMaxQualityMode=False and only applies the extended draw distance (MaxDrawDistanceScale 1.25) and mesh LOD bias (-1) changes. Players who already applied Ultra get the fix by re-applying Game Settings.
- UTF-8 BOM Fix for Local Script (Windows PowerShell 5.1):
  * Gears3_Multipatch_Tool.ps1 is now shipped as UTF-8 with BOM, so option [2] Local no longer fails with parser errors ("Unexpected token...", "The hash literal was incomplete") caused by the localized Russian / Polish objective strings being read as ANSI.
  * The BAT launcher also adds a missing BOM to the local and remote scripts before launching them.
- Backup Restore "Drive Not Found" Crash Fix:
  * Fixed a fatal error during installation / uninstall ("Cannot find drive. A drive with the name 'G' does not exist." at New-Item ... $targetDir) when the game folder had been moved or copied from another drive (different drive letter, copied or pre-patched install, removed external drive).
  * Root Cause: Backups in _files\Backups keep the absolute path of the game folder they were made in, and the restore step tried to write them back to that old, no longer existing location.
  * Solution: The restore step now detects the game folder the backups were made in and restores them into the current game folder. Backups whose drive no longer exists are skipped with a warning instead of stopping the tool.
- Cutscene Subtitle Timing Fix (Act 5 Chapter 3 Intro and Wreckage Outro):
  * Fixed the subtitles of the Act 5, Chapter 3 (Shattered Paradise) intro video (Azura_Intro) appearing about 6 seconds after the dialogue, and the Wreckage outro video (Wreckage_Outro) appearing about 2.5 seconds late.
  * Root Cause: The HD movies in the Jacinto build were re-cut with a shorter lead-in, but their subtitle timing files (GearGame\Movies\Azura_Intro.txt / Wreckage_Outro.txt) still hold the original 2011 frame timing.
  * Solution: Step 7 (Subtitles) now shifts every subtitle line earlier (Azura_Intro by 5.5 s, Wreckage_Outro by 1.5 s). The offsets were measured by running speech recognition on the movie dialogue and comparing it with every subtitle line. The original files are backed up and restored on uninstall, and an already adjusted or custom timing file is left unchanged.
- Act 5 Chapter 6 (Reckoning) Final Boss Death Crash Fix:
  * Fixed the game crashing right after the Lambent Queen / Tempest is killed with the Hammer of Dawn, when the ending movie should start. After restarting, the checkpoint loaded with the boss hovering in place, so the campaign could not be finished.
  * Root Cause: In the Jacinto build, SP_Rooftop_P starts the ending movie (Tower_Outro) on "BeginCinematic QueenDeath" and unloads every sublevel at that moment, instead of after the Queen death cinematic as in the original design. The event fires 1 s after the boss dies, but KILL_TEMPEST, which removes the boss, was only scheduled 0.1 s later from the level being unloaded, so it never ran. The live boss kept running its AI against unloaded flight nodes and Kismet objects.
  * Solution: TEMPEST_STAGE_4 (SP_Rooftop_01b_S.gear) now removes the boss first (KILL_TEMPEST at 1.0 s) and starts the ending 0.5 s later (three same-size edits: two Kismet links and one delay). Part of step 12; reverted on uninstall. If your save was made right before the crash, restart the chapter (or reload an earlier checkpoint) after installing.

v0.3.5
- Alt-Tab & Focus Window Hang (ANR / "Not Responding") Fix:
  * Resolved a critical deadlock where Alt-Tabbing away from the game and switching focus back caused the window to permanently freeze ("Not Responding" / white overlay) when running with VSync in windowed or borderless mode.
  * Root Cause: OneFrameThreadLag was set to False in SystemSettings, eliminating the 1-frame queue between Game Thread and Render Thread. When focus was regained under VSync, Direct3D 9 / DWM presentation synchronization blocked the Render Thread while the Game Thread waited on the render fence, completely halting the Win32 message loop (ANR).
  * Solution: Enforced OneFrameThreadLag=True across engine configurations and Game Settings, allowing decoupled frame processing and ensuring the Win32 message queue remains responsive during focus transitions and resolution changes.
- Storage Drive Optimization (SSD vs Mechanical HDD):
  * Resolved texture streaming delays and severe texture pop-in reported by players running the game from mechanical hard drives (HDDs).
  * Due to mechanical head seek times and low IOPS on HDDs, UE3's default behavior of evicting textures leaving camera view causes severe disk thrashing when turning around or exploring levels.
  * Added dedicated Storage Drive setting to both Game Settings (option 5) and Step 23 (Texture Streaming):
    - Automatically detects whether Gears of War 3 is installed on an SSD / NVMe or mechanical HDD via Windows storage APIs.
    - SSD / NVMe profile (Default): High-speed streaming (OnlyStreamInTextures=False, bEnableMipLevelFading=False, MinRequestedMipsToConsider=11, instant mip rendering, unloads distant textures to conserve VRAM).
    - HDD profile (Mechanical Hard Drive): Enables VRAM pre-caching (OnlyStreamInTextures=True) to retain streamed texture mips in video memory and avoid continuous disk read stalls. Enables mip alpha cross-fading (bEnableMipLevelFading=True) to mask mechanical read latency, lowers mip request threshold (MinRequestedMipsToConsider=1) so textures stream ahead of time from a distance, extends mip retention time (MinTimeToGuaranteeMinMipCount=12, MaxTimeToGuaranteeMinMipCount=30), and expands map loading streaming limits (LoadMapTimeLimit=60.0).
- Game Settings - FPS Limit & Graphics Quality Options:
  * Added FPS Limit option directly under VSync in Game Settings (Uncapped, 30, 60, 90, 120, 144, 165, 240, or custom value) using Unreal Engine 3 frame rate smoothing (bSmoothFrameRate & MaxSmoothedFrameRate).
  * Added dedicated "Graphics Quality:" sub-header with comprehensive standard graphical settings:
    - Overall Graphics Quality / Detail Mode: Low, Medium, High, Ultra (configures DetailMode, MaxDrawDistanceScale, Skeletal & Static Mesh LOD Bias).
    - Shadow Quality: Low, Medium, High, Ultra (adjusts DynamicShadows, LightEnvironmentShadows, Min/Max Shadow Resolutions, and Whole Scene Dominant Shadows).
    - Texture Quality: Low, Medium, High, Ultra (tunes LODBias across World, Character, Weapon, and Vehicle texture groups).
    - Foliage & Grass Quality: Low, Medium, High, Ultra (controls SpeedTreeLeaves and SpeedTreeFronds).
    - Anisotropic Filtering (AF): Off (1x), 2x, 4x, 8x, 16x (MaxAnisotropy).
    - Anti-Aliasing (AA): Off, FXAA / Temporal AA, MSAA 2x, MSAA 4x (bAllowTemporalAA, bAllowD3D9MSAA, MaxMultiSamples).
    - Ambient Occlusion (AO): On / Off toggle (AmbientOcclusion).

  * Removed color highlights from 8 (Uninstall), and 9 (Exit) for a cleaner, unified console presentation.

Screen-Door Dither Removed (bEnableMipLevelFading=False): Disabled the noisy dot-mesh mipmap fading transition effect during camera movement.
Crash-Safe Streaming: Resolved the fatal Assertion failed: Offset != INDEX_NONE crash by properly handling inlined UPK textures.
